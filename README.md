<h1>Forum - пет-проект</h1>
<p>Данный проект был написан на платформе <strong><a href="https://nodejs.org/en/">Node js</a></strong> с использованием библиотек:
<ul>
  <li>Express js</li>
  <li>EJS</li>
  <li>body-parser</li>
  <li>better-sqlite3</li>
</ul></p>
<img src='https://lite.host/assets/images/news/nodejs.png' width='40%'>
<h2>Для запуска на своём ПК:</h2>
<ol>
  <li><h4>Скачайте <strong><a href="https://nodejs.org/en/">Node js</a></strong></h4></li>
  <li><h4>Откройте cmd(Win + R)</h4></li>
  <img src='https://chemtable.ru/blog/wp-content/uploads/2014/11/windows-cmd-window.jpg' width='50%'>
  <li><h4>Перейдите в директорию с помощью команды:</h4></li>

```cmd
cd C:\path\to\your\directory
```
  <li><h4>Введите команды для запуска:</h4></li>
  
```cmd
# Сначало
npm i
# Потом 
node index.js
```
  <li><h4>Перейдите в браузере на http://localhost:3000/</h4></li>
</ol>
<p>Если у вас уже есть какие то посты то <b>просто удалите posts.db</b> и перезапустите</p>
